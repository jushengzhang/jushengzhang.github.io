Can LLMs Debug Robots by Editing Their Weights?

English: index.html
Chinese: zh.html
Published research: https://arxiv.org/abs/2611.09376
Code and experimental records: https://github.com/jushengzhang/robot-weight-debugging

The page replays archived simulator experiments. It runs no new inference.
Both sessions expose all 50 budget-charged requests. A request can contain multiple inputs or episodes.
Practice batches differ; intermediate feedback is not a training curve.
The four paired videos are selected held-out examples. Aggregate outcomes include regressions.

This is research release v1. Version 2 and real-robot experiments are in progress.
