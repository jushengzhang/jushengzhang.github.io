# Jusheng Zhang — Academic Homepage

Static academic homepage for Jusheng Zhang, prepared for GitHub Pages.

- Website: https://jushengzhang.github.io/
- Entry point: `index.html`
- Images, preview videos, and local fonts: `assets/`

## Publish

In the repository's **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**. The `.nojekyll` file enables direct static-file serving.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and visit http://localhost:8000.
